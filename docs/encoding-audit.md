## 防止后续重复引入

本地运行：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 scripts/test-encoding.py
python3 scripts/check-encoding.py
```

检查器只读取 Git 追踪的文本、文件名及待检查提交消息，不修改原文件，
不跟随符号链接读取仓库外内容，错误仅输出位置和原因。PNG/JPEG 等已声明
二进制类型不会作为文本解码。正常中文、合法 Unicode、未知状态占位符和
JavaScript 运算符不会因为“不是 ASCII”而被替换。

CI 对 PR 检查 base 到 head 的新增提交，对普通 push 检查 before 到 after；
标签和首次推送只检查当前提交。这样会阻止新引入的同类标题问题，而不是
为了通过 CI 去改写已发布的旧标题。也可通过 `--commit-range` 显式传入两个
完整 SHA 组成的范围。

故意包含损坏 Unicode 的文本测试夹具，可在对应行附加
`encoding-check: allow -- 具体测试原因`；这只豁免该行的 Unicode 内容探测，
不豁免无效 UTF-8 字节、文件名或提交消息。不要用它隐藏真正的产品文案损坏。
